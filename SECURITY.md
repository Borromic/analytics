# Security

## Reporting a vulnerability

Please report a vulnerability privately, never in a public issue: on this repository's **Security** tab, choose **Report a vulnerability** to open a private advisory with the maintainers.

Say what you found, how to reproduce it, and what it lets someone do. We'll confirm we received it within a few working days, keep you informed while it's fixed, and credit you in the advisory if you'd like.

## Supported versions

Fixes go into the latest release. Update to it before reporting, in case the issue is already fixed.
